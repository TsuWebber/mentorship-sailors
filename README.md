# 曼陀號水手：Webber × Andre

曼陀號閉幕分享用的共用頁，台下掃 QR code 會進到這一頁。整頁只有一個檔案 `index.html`，照片放在同一層。

## 怎麼修改

1. 在 GitHub 上打開 `index.html`，按鉛筆圖示編輯，或 clone 下來改。
2. 改完開一個 PR，Webber 確認後合併。
3. 合併到 `main` 後，GitHub Pages 會在一兩分鐘內自動更新網頁。

## 常見修改

- **照片**：放一張正方形照片，命名為 `andre.jpg`（或 `webber.jpg`），上傳到根目錄即可。沒有照片時會顯示名字首字母。
- **專案說明與連結**：在 `index.html` 裡搜尋專案名稱，修改 `<h3>`、`<p>` 和按鈕的 `href`。
- **還沒填的地方**：搜尋 `待更新`、`#todo`。
